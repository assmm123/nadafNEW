# قوالب قديمة — مُزالة من شجرة العرض

هذه ثلاثة قوالب كانت تخدم **التخطيط الأبيض القديم** قبل هوية نداف:

| الملف | كان يخدم |
|---|---|
| `layouts/app.blade.php` | ثماني صفحات: الدخول · التسجيل · الاستعادة · البحث · التواصل · المحتوى · تفاصيل الطلب |
| `partials/header.blade.php` | هيدر التخطيط القديم |
| `partials/footer.blade.php` | تذييل التخطيط القديم |

**لماذا أُزيلت**: بعد نقل الصفحات الثماني إلى `layouts.nad`، لم يبقَ ملف
يستدعيها إطلاقًا — صارت **كودًا ميتًا** يحمل `bg-white` و`text-navy-900`
(157 موضعًا من التنسيقات القديمة) ويلوّث أي فحص لاحق للتنسيقات المتراكمة.

**ولم تُحذف** لأن المشروع ليس مستودع git، فالحذف غير قابل للاستعادة.

**لإرجاعها**: انقلها إلى مواضعها السابقة.
